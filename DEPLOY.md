# ITKhabar Command Center — Deployment Guide

## What You Need

| Item | Purpose | Required? |
|------|---------|-----------|
| GitHub account | Host code + auto-refresh | Yes |
| Vercel account | Free hosting (auto-deploys from GitHub) | Yes |
| NewsAPI key | Live news headlines | Optional (free tier: newsapi.org) |

---

## Step 1: Create GitHub Repository

1. Go to **github.com/new**
2. Repository name: `itkhabar-dashboard`
3. Set to **Public** (required for free Vercel) or Private (Vercel Pro)
4. Click **Create repository**
5. Follow the "push an existing repository" instructions:

```bash
cd it-dashboard
git init
git add index.html fetch_data.py vercel.json .github/ logo-main.png logo-app.png
git commit -m "Initial commit: ITKhabar Command Center"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/itkhabar-dashboard.git
git push -u origin main
```

---

## Step 2: Deploy on Vercel (free)

1. Go to **vercel.com** → Sign in with GitHub
2. Click **"Add New Project"**
3. Import your `itkhabar-dashboard` repo
4. Framework: **Other**
5. Build command: leave empty
6. Output directory: `.`
7. Click **Deploy**
8. Your dashboard is live at `https://itkhabar-dashboard.vercel.app` (or custom domain)

Every push to `main` auto-deploys within ~30 seconds.

---

## Step 3: Enable Live Data (GitHub Actions)

The workflow `.github/workflows/refresh.yml` runs `fetch_data.py` three times daily:
- **5:00 AM IST** — pre-market India
- **4:30 PM IST** — post-market India  
- **10:00 PM IST** — post-market US

It commits `data.json` to the repo, which Vercel auto-deploys.

### Add NewsAPI key (optional, for live news):
1. Go to **newsapi.org** → Sign up (free)
2. Copy your API key
3. In GitHub: **Settings → Secrets → Actions → New repository secret**
   - Name: `NEWSAPI_KEY`
   - Value: your key

### Manual trigger:
- GitHub → Actions → "Refresh Dashboard Data" → "Run workflow"

---

## Step 4: Custom Domain (optional)

1. In Vercel dashboard → your project → **Settings → Domains**
2. Add your domain (e.g. `dashboard.itkhabar.com`)
3. Point DNS:
   - **CNAME**: `dashboard` → `cname.vercel-dns.com`
   - Or **A record**: `76.76.21.21`
4. Vercel auto-provisions SSL

```
│   └── workflows/

└── DEPLOY.md           # This file
```

---

## How Live Data Works

1. **GitHub Actions** runs `fetch_data.py` on schedule
2. Script pulls from Yahoo Finance (stock prices, indices) + NewsAPI (headlines)
3. Writes `data.json` and commits to repo
4. **Vercel** auto-deploys the updated `data.json`
5. **Dashboard** fetches `data.json` on load and updates all tickers, cards, and news

The dashboard works offline too — it has built-in static data as fallback.

## Alternative: Netlify (instead of Vercel)

1. Go to **netlify.com** → Sign in with GitHub
2. "New site from Git" → Select your repo
3. Build command: leave empty
4. Publish directory: `.`
5. Deploy

Same auto-deploy from GitHub pushes.

---

## Alternative: GitHub Pages (simplest, no build)

1. GitHub repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main`, folder: `/ (root)`
4. Save
5. Live at `https://YOUR_USERNAME.github.io/itkhabar-dashboard/`

Note: GitHub Pages is public-only and has a 10-minute cache.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Data not updating | Check GitHub Actions tab for failed runs |
| yfinance errors | Market may be closed; data updates on next trading day |
| NewsAPI 429 | Free tier is 100 requests/day; reduce cron frequency |
| Vercel 404 | Ensure `index.html` is at repo root |
